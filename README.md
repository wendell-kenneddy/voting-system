# Voting System

Projeto para AB2 da disciplina de Paradigmas de Linguagens de Programação.

Integrantes:

- Jeremias Victor Marinho Santos
- Wendell Kenneddy Gama da Silva

O projeto compara duas implementações de uma API de votação reativa com TypeScript, Express, RxJS e SSE. A especificação comum está em [docs/SPECS.md](docs/SPECS.md).

- [with-harness](with-harness/) contém instruções para agentes, regras de arquitetura, lint, testes e validação integrada.
- [without-harness](without-harness/) contém a implementação e os testes sem o mesmo conjunto de verificações arquiteturais.
- [Relatório final](docs/RELATORIO_FINAL.md) apresenta a comparação, os resultados, os limites das evidências e os comandos de reprodução.
